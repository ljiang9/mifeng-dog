# 🐝🐶 蜜蜂小狗肿胀指数测试

> 致敬 2026-10-03 小沈阳"蜜蜂小狗"热梗，善意玩梗，开心就好。
> 本项目纯属娱乐，不构成任何医疗建议；眼睛不适请及时就医。

## 玩法

问卷式 CLI：回答 7 个问题（昨晚睡了几小时、哭没哭、吃咸了没、过敏没、
揉眼睛没、熬夜刷手机没、照镜子被吓到没），按权重算出 0-100 的
**蜜蜂小狗指数**，分档给出毒舌但善意的评语：

| 指数 | 档位 | 评语画风 |
|------|------|----------|
| 0-20 | 清澈小狗 | 眼睛清澈得像小狗刚睡醒 |
| 21-40 | 微肿小狗 | "用对了不"的边缘试探 |
| 41-60 | 蜜蜂小狗预备役 | 再努努力就能持证上岗 |
| 61-80 | 蜜蜂小狗本狗 | 眼睛肿成表情包 |
| 81-100 | 肿胀天花板 | 建议直接报备蜜蜂小狗，用对了不！ |

评语多玩梗（"用对了不"、"更蜜蜂了"、"眼睛肿成表情包"），
但保持善意不刻薄——高分档最后都会提醒好好休息。

## 用法

```bash
# 交互测试（需要终端）
python3 -m mifeng_dog

# 自动测试：随机生成 10 个虚拟用户
python3 -m mifeng_dog --auto

# 指定人数和种子（可复现）
python3 -m mifeng_dog --auto --games 20 --seed 7

# 打印答题明细
python3 -m mifeng_dog --auto --games 3 --verbose
```

## 实现说明

- 纯 Python 标准库（`argparse`/`random`/`sys`），Python 3.10+。
- 7 题权重总和上限恰好 100（代码内有 `assert` 兜底）。
- `--auto` 用 `random.Random(seed)`，同种子结果完全可复现。
- 非终端环境下交互模式会中文提示并退出（exit 2），请用 `--auto`。

## 真实验证记录

- `python3 -m py_compile mifeng_dog.py __main__.py`：通过。
- 单元测试 10 项（见下方）：全过。
  - 全部选最低分选项 → 指数 0，档位"清澈小狗"
  - 全部选最高分选项 → 指数 100，档位"肿胀天花板"
  - 权重求和与逐题权重一致
  - 档位边界：20/21、40/41、60/61、80/81 均正确分档
  - 题数不对 / 选项越界 / 非整数选项 → 抛 `ValueError`
  - 同种子 `--auto` 两次运行输出完全一致
- `python3 -m mifeng_dog --auto --games 10 --seed 42`：10 个虚拟用户全部出分，
  最低 39、最高 79、平均 55.5（真实运行数字，同种子可复现）。

## 已知局限（诚实版）

- 纯娱乐向的伪科学测试，指数没有任何医学依据，不要当真。
- 评语是写死的模板，多玩几次会背下来。
- 交互模式只支持数字选择，不支持自然语言回答。
- 文本界面，无图形/存档/网络对战。
